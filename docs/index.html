What the analysis found

Retention drops

7-day retention fell from 19.0% to 18.2% (p = 0.002, still significant after Holm correction). The Bayesian probability that gate 40 is better is 0.08%.

The split is off

Gate 40 got 789 extra players (SRM, p = 0.009), almost all of them players who never reached level 30. In the worst case the drop shrinks to −0.5 pp (p = 0.056).

Recommendation

Keep the gate at level 30, fix the assignment bug, and if product still wants gate 40, run a confirmation test with about 96K players per group.
